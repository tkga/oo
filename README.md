# สมุดรายรับรายจ่าย

แอพบันทึกรายรับรายจ่ายแบบหน้าเว็บไฟล์เดียว ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้อง build

## ฟีเจอร์

- หน้าหลัก: เงินคงเหลือ สรุปรายเดือน กราฟสัดส่วนรายจ่ายแยกหมวด อันดับหมวดที่ใช้มาก/น้อย
- บันทึก: เพิ่ม แก้ไข ลบรายการ เลือกหมวดและช่องทางชำระเงิน ค้นหาและกรอง
- บัญชี: ยอดของแต่ละช่องทางชำระเงิน หักหรือเพิ่มอัตโนมัติตามรายการ รองรับบัตรเครดิตและโอนระหว่างบัญชี
- สถิติ: รายรับเทียบรายจ่ายย้อนหลัง 6 หรือ 12 เดือน ตารางสรุปแต่ละหมวด
- งบ: ตั้งงบรายหมวด เตือนเมื่อใกล้เกินหรือเกินงบ
- เป้าออม: ตั้งเป้าหมาย ฝาก ถอน ดูความคืบหน้า
- ตั้งค่า: จัดการหมวดหมู่ ช่องทางชำระเงิน สกุลเงิน ปี พ.ศ. ธีม ส่งออก/นำเข้าข้อมูล

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ที่ใช้เปิดเท่านั้น ไม่ส่งไปที่ไหน

## เอาขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `ledger`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ ได้แก่ `index.html`, `manifest.webmanifest`, `sw.js`, โฟลเดอร์ `icons`, `README.md`
3. ไปที่ Settings > Pages เลือก Source เป็น "Deploy from a branch" เลือกสาขา `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1 นาที จะเปิดได้ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ติดตั้งลงมือถือ

เปิดลิงก์ด้านบนในเบราว์เซอร์ของมือถือ

- Android (Chrome): เมนู ⋮ > "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
- iPhone (Safari): ปุ่มแชร์ > "เพิ่มไปยังหน้าจอโฮม"

แอพจะเปิดเต็มจอและใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

## ข้อควรรู้

- ข้อมูลแยกตามเบราว์เซอร์และเครื่อง มือถือกับคอมไม่ซิงก์กัน ถ้าจะย้ายให้ใช้ ตั้งค่า > ส่งออกไฟล์สำรอง JSON แล้วนำเข้าอีกเครื่อง
- ถ้าล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ ข้อมูลจะหาย ควรส่งออกไฟล์สำรองเป็นระยะ
- ถ้าแก้ไขไฟล์แล้วเครื่องที่ติดตั้งไว้ไม่อัปเดต ให้เปลี่ยนเลขเวอร์ชัน `CACHE` ใน `sw.js`
- ฟอนต์โหลดจาก Google Fonts ครั้งแรกต้องมีอินเทอร์เน็ต หลังจากนั้นเก็บไว้ในเครื่อง
